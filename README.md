# Модуль NovaPoshta для OkayCMS

> **В розробці.** Не встановлюйте в робочий магазин: модуль ще не створює ТТН.

Один модуль Нової Пошти для OkayCMS замість трьох: вибір відділення, поштомату чи
адреси в кошику, розрахунок доставки, створення й трекінг ТТН в адмінці.

## Що вже вміє (0.5.0)

- Сторінка налаштувань (Модулі → Мої модулі → NovaPoshta): ключ API Нової Пошти.
- Ключ перевіряється при збереженні в обох API НП — новому (відділення, розрахунок,
  трекінг) і старому (післяплата, контроль оплати, ТТН на адресу). Результат видно
  на сторінці з порадою, що робити далі.
- Ключ, який НП не приймає, не замінює збережений. Ключ без доступу до нового API
  і ключ, який не вдалося перевірити, зберігаються з попередженням.
- Повний ключ ніде не показується: на сторінці лише останні 4 символи.

- Довідники Нової Пошти в базі модуля: відділення й поштомати України (~55 тис.),
  населені пункти (~27,5 тис.) і популярність міст. Повне завантаження — до кількох
  хвилин, щоденне оновлення змінами — секунди. Без ключа API завантажуються все,
  крім популярності міст.
- Групи пунктів для покупця («Відділення», «Поштомат» за замовчуванням): назва,
  порядок, які категорії НП показувати.

- Кошик: покупець вибирає населений пункт (пошук і кнопки популярних міст), групу
  й відділення чи поштомат. Список пунктів — сторінками по 100 з пошуком за номером
  чи вулицею. Пункти, які не приймуть замовлення за вагою чи сумою, видно сірим із
  причиною (вага, сума, об'єм). Вигляд береться з теми магазину (перевірено на okay_shop, vibe_shop і
  похідних від okay_shop).
- Кнопки популярних міст для кошика налаштовуються на тій самій сторінці.
- Вибір перевіряється на сервері (місто, пункт цього міста, видима група, вага,
  сума) і зберігається із замовленням як знімок назв: місто й пункт видно на
  сторінці замовлення та в листах покупцю й адміністратору. Зареєстрованому
  покупцю кошик пропонує пункт з його останнього замовлення.

- Ціна доставки до вибраного пункту рахується в Новій Пошті й видна в кошику там, де
  тема показує ціну способу доставки й підсумок. Ціну рахує лише сервер, вона ж іде
  в замовлення; розрахунок живе годину й прив'язаний до пункту, оплати й кошика.
  Ціну не рахують, коли в способі доставки увімкнено «Приховати ціну» або кошик
  дорожчий за поріг безкоштовної доставки.
- Якщо Нова Пошта не відповідає, замовлення оформлюється з ціною способу доставки,
  а лист адміністратору про це попереджає.
- Післяплата — це спосіб оплати з позначкою «Післяплата Новою Поштою» (налаштування
  модуля). «Грошовий переказ» додає комісію НП до ціни доставки, «Контроль оплати»
  ціну для покупця не змінює.
- Відправник (населений пункт і відділення), вага й об'єм за замовчуванням — у
  налаштуваннях модуля. Без відділення відправника ціна не рахується.
- Об'єм варіанта товару, м³ — поле в картці товару. Поштомати й відділення, у які
  відомий об'єм не вміщається, видно сірим із причиною.
- Орієнтовна дата доставки — лише якщо її увімкнути в налаштуваннях (за замовчуванням
  вимкнено). Тоді вона є й на сторінці замовлення та в листах.
- Ціни Нової Пошти в гривнях переводяться в основну валюту магазину; потрібна валюта
  з кодом UAH.

- Доставка на адресу (режим способу доставки «Адреса»): населений пункт (усі, не лише
  з відділеннями), вулиця з підказками Нової Пошти, будинок, квартира, під'їзд, поверх,
  примітка для кур'єра. Вулицю можна ввести й без підказки. Ціна й термін на адресу —
  з калькулятора НП; куди НП адресно не доставляє — ціну уточнить менеджер.
- Підйом на поверх (налаштування «Підйом на поверх у кошику», типово вимкнено): покупець
  бачить опцію лише коли підйом платний або вага частини товарів невідома; доплату дає
  калькулятор НП. «Є ліфт» — разом із підйомом. Адреса й підйом — на сторінці замовлення
  та в листах.
- Межа вартості пункту порівнюється із сумою кошика в гривнях.

Доступ до сторінки мають менеджери з правом «Доставка».

## Оновлення модуля

Після заміни файлів модуля натисніть «Оновити» в «Модулі → Мої модулі». До того модуль
не реєструє нових полів (позначка післяплати, об'єм товару, ціна в знімку замовлення):
вітрина працює, але післяплата й об'єм товарів не враховуються, а ціна доставки не
потрапляє в знімок замовлення модуля.

## Як підключити спосіб доставки

1. Налаштування → Доставка → створіть спосіб і виберіть модуль «Nova Poshta».
2. У полі «Що вибирає покупець» виберіть «Відділення чи поштомат» (з тим варіантом,
   як ви передаєте посилки). Варіанти «Адреса» поки що працюють як звичайна доставка
   без вибору: адреса, ціна й термін доставки з'являться в наступній версії.

## Потрібен планувальник OkayCMS

Довідники оновлює задача планувальника; без cron вони не завантажаться. На сервері
має щохвилини запускатися:

```
* * * * * php /шлях/до/сайту/ok scheduler:run
```

Якщо cron немає, блок «Довідники» в налаштуваннях модуля прямо про це скаже.

## Перевірено

Чиста OkayCMS 4.5.3 і [форк](https://github.com/devSviat/OkayCMS-Fork), PHP 8.5.

## Тести

Тести лежать у `tests/` і не потрапляють в архів релізу. Жоден тест не звертається
до Нової Пошти, крім `tests/Api/LiveApiTest.php`: він запускається лише зі змінною
`NP_TEST_API_KEY` (тестовий ключ, не ключ магазину):

```sh
bin/lab exec stock env NP_TEST_API_KEY=<ключ> php vendor/bin/phpunit tests/Modules/Sviat/NovaPoshta --filter LiveApiTest
```
